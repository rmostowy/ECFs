# ECFs v1.0.2: analysis code and ECF database

Database of 13,035 Evolutionarily Conserved Fragments (ECFs) identified in proteins from 5,396 RefSeq bacteriophage genomes, grouped into 3,167 ECF families (EFs). The resource accompanies the manuscript:

*Evolutionarily Conserved Fragments reveal modular architecture and expand functional coverage in bacteriophage proteins*
(Smug\*, Szczepaniak\*, Leconte, Dunin-Horkawicz & Mostowy; in preparation).

This release contains both parts of the resource:

- the **analysis code** that builds the database and generates the figures
  (the source archive of this release; see the README), archived on Zenodo with
  its own DOI for this version;
- the **ECF database files** listed below, attached to this release. GitHub does
  not assign DOIs to attached files and Zenodo archives only the source code, so
  the same database is also deposited at FigShare
  (<https://doi.org/10.6084/m9.figshare.34887162>).

Code and database share one version series. v1.0.1 contained the code only;
v1.0.2 is the first release that also carries the database files.

## Files

| File | Contents |
|---|---|
| `ecf-hhsuitedb.tar.gz` | HH-suite database of ECF profiles (prefix `ecf_db`): `a3m`, `hhm` and `cs219` ffdata/ffindex files |
| `ecf-a3m.tar.gz` | The same alignments as individual `.a3m` files, one per ECF (13,035 files) |
| `ecf-metadata.csv` | One row per ECF: family, length and best ECOD, Pfam and functional annotations |
| `SHA256SUMS.txt` | SHA-256 checksums of the three files above |

## Quick start

Download the files into one folder, then verify and unpack:

```bash
shasum -a 256 -c SHA256SUMS.txt     # or: sha256sum -c SHA256SUMS.txt
tar -xzf ecf-hhsuitedb.tar.gz
tar -xzf ecf-a3m.tar.gz             # optional
```

Search a query alignment against the ECF database with HH-suite:

```bash
hhsearch -i query.a3m -d hhsuitedb/ecf_db -o query.hhr
```

ECF names in the search results (e.g. `ecf_00001`) match the file names in
`a3m/` and the `ecf.name` column of `ecf-metadata.csv`.

## Databases
ECFs were searched against external databases using hhsearch:

- PHROGs (v4)
- ECOD (version 20230309)
- Pfam (v37)

## ecf-metadata.csv columns

| Column | Description |
|---|---|
| `ecf.name` | ECF identifier (e.g. `ecf_00001`) |
| `EF` | ECF family the ECF belongs to (e.g. `EF0001`) |
| `ecf.length` | Length of the ECF profile, in amino acids |
| `ecf.size` | Number of sequences within the ECF profile/alignment |
| `top.ecod.hit.tid` | ECOD T-group ID of the best ECOD hit (e.g. `101.1.4`) |
| `top.ecod.hit.tname` | ECOD T-group name of that hit |
| `top.pfam.hit.accession` | Pfam accession of the best Pfam hit (e.g. `PF08667`) |
| `top.pfam.hit.description` | Pfam description of that hit |
| `top.functions` | Functional annotations linked to the ECF (PHROG/antidefence-derived), separated by `\|` |

## Requirements

[HH-suite](https://github.com/soedinglab/hh-suite) 3.3.0 (the database was
built with this version).
